# Following List → CSV

A desktop Chrome/Edge extension that collects accounts from another Instagram profile’s **Following** dialog and exports a CSV suitable for Google Sheets. It uses the Instagram session already signed in in the browser. It never asks for passwords, reads cookies, uses private API endpoints, or uploads collected data.

**[Download the extension ZIP](https://github.com/saschasteffens/ig-following-export/raw/refs/heads/main/downloads/following-export-0.1.0.zip)**, extract it, and open **GETTING_STARTED.html** inside for step-by-step installation instructions. No coding is needed.

For installation and use, open **GETTING_STARTED.html**. The downloadable ZIP is generated by `npm run package` or `python3 scripts/package.py`; extract it and load its `following-export` directory through Chrome/Edge’s **Load unpacked** option.

## What it does

- Opens a profile by username, then collects from the Following window you open.
- Scrolls at a fixed, modest pace, deduplicates account links, and shows a count.
- Supports pause, resume, partial CSV downloads, and explicit clearing.
- Stops if the profile changes, the dialog closes, a visible Instagram alert appears, there is no growth for about 18 seconds, or ten minutes of automatic scrolling elapse.
- Exports source username, followed username, display name when available, profile URL, and collection time (UTC).
- Escapes CSV fields, includes a UTF-8 BOM, and neutralizes spreadsheet formula prefixes.

## Limits and privacy

This tool only reads the rendered list that your login can view. It cannot unlock private accounts or guarantee that Instagram exposes the entire list. A stopped scan is not proof of completeness. It currently requires Instagram’s `/username/following/` URL and a rendered account list in a dialog; future layout changes may require updates. Display names are best effort.

Data lives in the Instagram tab’s memory, continues collecting if the popup closes, and disappears when the tab refreshes or closes. Download first. Starting a different list requires clearing the previous one. No account credentials, Google credentials, database, server, or paid service is required. Google Sheets uses manual CSV import in this version.

## Development

Use the existing checkout at `/workspace/ig-following-export`; cloud tasks are already isolated and do not need a Git worktree. Runtime extension code is plain JavaScript and has no third-party dependencies or build step.

Prerequisites: Node.js 22+, npm, Python 3 for packaging, and Chromium for browser tests. This cloud machine provides Node 24, Python 3, and `/usr/bin/chromium`.

```sh
cd /workspace/ig-following-export
npm ci --ignore-scripts --cache /tmp/ig-export-npm-cache
npm test
npm run test:browser
npm run package
```

Use `CHROMIUM_PATH=/path/to/chromium npm run test:browser` on a different machine. The scripts never download browsers automatically. No running service is needed. To check a change against live Instagram, reload the unpacked extension on the extensions page, refresh the Instagram tab, and start a fresh collection.

## Validation scope

Node tests cover URL targeting, CSV escaping, spreadsheet formula protection, and permission declarations. Playwright tests use a real Chromium browser with intercepted, representative Instagram pages. They exercise incremental scrolling, duplicate rows, pause/resume, target changes, no-growth handling, alerts, popup interactions, retrying after errors, and actual CSV downloads.

The tests use a small Chrome messaging adapter, not a live extension install: this cloud machine’s managed Chromium blocks installing local extensions. Automated checks do not prove compatibility with Instagram’s current live UI. A real-account check remains necessary in your own desktop browser. No live account or Instagram password was used during development.
