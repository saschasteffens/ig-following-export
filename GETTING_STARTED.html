Following list → spreadsheet.

Export the accounts someone follows on Instagram. No coding needed. This first version works in desktop Chrome and Microsoft Edge.

Updating from version 0.1.0? Download and extract the new ZIP. Open chrome://extensions (or edge://extensions), remove the old Following List → CSV extension, then follow the installation steps below to load the new folder. Refresh Instagram before trying again. Version 0.1.1 fixes Following windows that keep the profile’s address unchanged.

1. Install once

  1. Extract the ZIP file first. On Windows, right-click it and choose Extract All. On a Mac, double-click it. Keep the extracted folder somewhere permanent, such as Documents.
  2. Open Chrome. Type chrome://extensions into its address bar and press Enter. In Edge, use edge://extensions.
  3. Switch on Developer mode. This allows installing this local extension.
  4. Click Load unpacked. Choose the following-export folder inside the extracted ZIP. It is the folder containing manifest.json.
  5. Click the puzzle-piece Extensions button beside the address bar. Pin Following List → CSV so it is easy to find.

2. Export a list

  1. Go to instagram.com and sign in normally. Your password stays with Instagram.
  2. Open the profile whose Following list you want. You can also enter their username in the extension and click Open profile.
  3. On that profile, click the Following number. Leave the list open.
  4. Click the extension, then Start collecting. It will scroll the open list and count unique accounts. You can close the extension popup while it works; keep the Instagram tab open.
  5. Reopen the extension to check progress. Click Pause whenever you want, then Download CSV. You can also download a partial list while collection is running.
Check the count. Instagram may limit which accounts it shows. “Scrolling stopped” means no new accounts appeared for a while; it does not guarantee a complete list. You can scroll manually and choose Continue scanning. Download before refreshing or closing the Instagram tab, because that clears the collection.

3. Open in Google Sheets

  1. Open a blank spreadsheet in Google Sheets.
  2. Choose File → Import → Upload → Browse, then select the downloaded CSV.
  3. Choose Insert new sheet(s), then Import data. If asked for a separator, choose Comma.

If something does not work

Make sure you are on instagram.com, the Following list is open, and your login can see it. This tool cannot unlock private lists. If Instagram displays a restriction, pause and follow Instagram’s instructions. If it collects zero accounts, Instagram may have changed its page layout; send the error message back in chat.

Some work or school browsers block local extensions. In that case, use a personal browser if permitted, or ask the browser administrator.

This is an independent tool, not an Instagram product. It sends no collected data to an external server. The browser runs it locally, and you choose when to download the CSV.
